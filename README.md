# VividVoices

VividVoices is the front end of a chat app, built with React. Right now it is the user interface only. There is no backend in this repo, and the chats and contacts are sample data made with Faker.

## Stack

- React 18 (Create React App)
- Material UI (MUI)
- React Router
- Framer Motion, Phosphor icons, emoji-mart, SimpleBar

## What is in it

- Dashboard layout with a sidebar and a chat list
- Chat window with a header and a message input with an emoji picker
- Light and dark mode and theme settings
- 404 page

## Run it locally

```
npm install
npm start
```

Then open `http://localhost:3000`.
